# AI Prompts for Developers

## Explain code

```text
Explain the following code as a senior developer mentoring a beginner. Start with what the code is intended to do, then walk through the important parts, identify dependencies or assumptions, and finish with the most important lessons.

Code:
[PASTE CODE]
```

## Debug an error

```text
Analyze this error as a senior developer. Identify the most likely root cause, explain why it happens, give the smallest practical fix, and provide a corrected example. Do not rewrite unrelated code.

Language/framework:
[LANGUAGE/FRAMEWORK]

Error:
[PASTE ERROR]

Relevant code:
[PASTE CODE]
```

## Code review

```text
Review the following code for correctness, security, maintainability, performance, and readability. Prioritize actual problems over stylistic preferences. List findings by severity and provide focused fixes.

Code:
[PASTE CODE]
```

## Plan a feature

```text
Act as a senior software architect. Turn this feature request into an implementation plan. Include requirements, data changes, API changes, frontend/backend tasks, edge cases, testing, and deployment considerations. Clearly mark assumptions.

Feature request:
[PASTE REQUEST]
```

## Refactor safely

```text
Suggest a safe refactoring strategy for the following code. Preserve behavior and public interfaces unless a change is explicitly necessary. Explain the risks, propose incremental steps, and show the final refactored code.

Code:
[PASTE CODE]
```
