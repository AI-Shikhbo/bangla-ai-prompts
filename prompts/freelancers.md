# AI Prompts for Freelancers

## Write a professional client reply

```text
Act as an experienced freelancer. Write a concise, friendly, professional reply to the following client message. Show that I understand the requirement, ask only necessary questions, and avoid sounding desperate or overly sales-focused.

Client message:
[PASTE MESSAGE]
```

## Turn requirements into a project plan

```text
Act as a senior project manager. Convert these client requirements into a clear implementation plan. Break the work into milestones, tasks, dependencies, assumptions, and deliverables. Flag anything that is ambiguous and needs clarification.

Requirements:
[PASTE REQUIREMENTS]
```

## Improve a proposal

```text
Rewrite my freelance proposal so it is concise, specific to the client's project, confident but not exaggerated, and focused on the client's outcome. Do not invent experience or results.

Job:
[PASTE JOB]

My draft:
[PASTE PROPOSAL]
```

## Estimate a project

```text
Act as a senior freelancer. Analyze the following project requirements and suggest a reasonable effort estimate. Break the estimate into tasks and explain the main factors that could increase or decrease the effort. Do not assume missing requirements without clearly labeling them.

Project:
[PASTE REQUIREMENTS]
```

## Create client handoff documentation

```text
Create professional client handoff documentation for this project. Include what was delivered, how to use it, important configuration details, maintenance notes, limitations, and recommended next steps. Keep the language understandable for a non-technical client.

Project details:
[PASTE DETAILS]
```
