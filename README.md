# Bangla AI Prompts

A practical collection of reusable AI prompts in Bangla and English for students, freelancers, developers, content creators, and professionals.

## Why this repository?

AI tools are powerful, but good results often depend on giving them clear instructions. This repository collects practical prompts that can be adapted for everyday work, learning, research, writing, coding, and productivity.

## Example prompts

### 1. Learn a difficult topic

```text
Act as a patient teacher. Explain [TOPIC] in simple Bangla for a beginner. Start with the basic idea, then explain the important concepts step by step. Use practical examples and finish with 5 short questions to test my understanding.
```

### 2. Improve writing

```text
Act as a professional editor. Improve the following text for clarity, grammar, structure, and readability while preserving the original meaning and tone. Give me the improved version first, followed by a short list of the most important changes.

Text:
[PASTE TEXT]
```

### 3. Research a topic

```text
Act as a research assistant. Help me understand [TOPIC]. Break the subject into the most important subtopics, explain what I should learn first, identify common misconceptions, and suggest reliable sources or search queries for further research. Clearly distinguish facts from assumptions.
```

### 4. Debug code

```text
Act as a senior software developer. Analyze the following code and identify the root cause of the problem. Explain why it happens, provide the smallest practical fix, and then show the corrected code. Do not rewrite unrelated parts.

Language/framework:
[LANGUAGE OR FRAMEWORK]

Code:
[PASTE CODE]

Error:
[PASTE ERROR]
```

### 5. Create a content plan

```text
Act as a content strategist. Create a practical 30-day content plan about [TOPIC] for [AUDIENCE]. Include the topic, format, primary goal, suggested hook, and a clear call to action for each day. Prioritize useful educational content over promotional posts.
```

## Using the prompts effectively

Replace the text inside `[BRACKETS]` with your own information. For better results, provide context, constraints, examples, the desired audience, and the exact format you want in the final answer.

A useful prompt usually answers:

1. **Who should the AI act as?**
2. **What exactly should it do?**
3. **What context does it need?**
4. **What constraints should it follow?**
5. **What should the final output look like?**
